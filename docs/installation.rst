============
Installation
============


Stable release
--------------

Use pip to install wofry:

.. code-block:: console

    $ python -m pip install wofry


From sources
------------

The sources for wofry can be downloaded from the `Github repo`_.

.. code-block:: console

    $ git clone https://github.com/oasys-kit/wofry

Once you have a copy of the source, install it with:

.. code-block:: console

    $ pip install -e .


.. _Github repo: https://github.com/oasys-kit/wofry
